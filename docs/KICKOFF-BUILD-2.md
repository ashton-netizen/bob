## Why the order is what it is
- Part A before Part B because the plugin on main today cannot adopt anything: it has no `/bob adopt`, no human-typed approval route, and a preflight that would STOP on an adopted repo for a missing `bob/schema.json` and `docs/project-status.md`. Those three gaps were read from `hooks/register.tsx` and `scripts/preflight.sh` on 21 October 2026.
- INC-00 exists because Gate A engages the moment `bob/brief.json` lands: the commit that lands the adopt is itself a governed write, so it needs an approval, and that approval is the first live test of `/bob approve` and the first live Gate A denial. Letting the adopt command commit from inside the plugin would bypass the gate, which the plan's kill criteria forbid.
- The dummy pull request comes before the adopt pull request so that the first real merge into AquaAgent is already behind a check that has been seen red.
